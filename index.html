Uncompromising Security

Military-Grade Cryptographic Vault

Your secrets never touch disk in plaintext. Horizon's vault engine applies AES-256-GCM authenticated encryption with a PBKDF2-SHA256 key derivation function at 210,000 iterations —” well above NIST and OWASP recommendations.

AES-256-GCM

Authenticated encryption with built-in integrity verification for every stored secret.

210,000 PBKDF2 Iterations

Key stretching far exceeds industry standard requirements, making brute-force attacks computationally infeasible.

Independent Master Key

Vault credentials are fully decoupled from login passwords —” changing your account password never exposes secrets.

Zero-Downtime Key Rotation

Rotate master passphrases at any time. Horizon decrypts and re-encrypts all secrets in-memory with zero data loss.

Questions & Answers

Frequently Asked Questions

Is Horizon PM really free?
Yes. Horizon PM is 100% free and open-source under the Apache License 2.0. You can download, use, and modify it for commercial purposes with proper attribution.
Does it work without internet?
Absolutely. Horizon is built on an offline-first SQLite WAL database. All core functionality works completely offline. Cloud synchronization is optional and runs in the background when connectivity is available.
Which operating systems are supported?
Horizon PM officially supports both Windows (64-bit) and macOS (native DMG & ZIP installers for Apple Silicon M1/M2/M3/M4 and Intel Macs). Linux support is also planned for future updates.
How secure is the secrets vault?
The vault uses AES-256-GCM authenticated encryption with PBKDF2-SHA256 key derivation at 210,000 iterations — significantly exceeding NIST SP 800-132 and OWASP recommendations. Plaintext secrets never touch disk.
Can I use my existing cloud storage?
Yes. Horizon supports MongoDB Atlas, Google Drive, Microsoft SharePoint Online, OneDrive for Business, and Azure Key Vault as sync backends. You can mix and match, or use none at all.
How do I get started?
Download the latest installer from our GitHub Releases page. After installation, Horizon creates a default admin account (username: admin, password: horizon123). Change your password on first login.
Can I contribute to the project?
Absolutely! Fork the repository on GitHub, create a feature branch, and open a pull request. Please review our Contributing Guidelines and Code of Conduct before submitting.
